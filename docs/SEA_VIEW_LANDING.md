# Sea View в каталоге

Адреса: `/ru/property/sea-view/`, `/en/property/sea-view/`, `/th/property/sea-view/`.

В подборку попадают только активные опубликованные объекты на продажу с явным подтверждением вида на море:

1. У карточки вручную указана характеристика «Вид на море» / «Sea view» / «วิวทะเล».
2. Карточка сопоставлена с активной группой AREALISTING, в которой есть доступное предложение с `sea_view=true`.

После очередной синхронизации AREALISTING значение у предложения обновляется. Страница читает его напрямую, поэтому повторно сопоставлять объект и запускать отдельный импорт характеристик для попадания в раздел не нужно. Если характеристики карточки находятся под управлением AREALISTING, устаревшая характеристика в карточке не удерживает объект в подборке после смены флага на `false`. Если модератор заблокировал изменение характеристик, ручной выбор сохраняет приоритет.

Миграция `properties.0026_sea_view_feature` добавляет характеристику в справочник, если её ещё нет. Для объектов без AREALISTING модератор назначает эту характеристику в карточке. Название или описание объекта само по себе не считается подтверждением вида.

При отсутствии подходящих объектов страница остаётся доступной пользователям, но получает `noindex` и не включается в sitemap. Перед просмотром нужно уточнять конкретный этаж, комнату и возможную застройку перед видом. Вид на море не равен расположению у пляжа.

Для выпуска после обновления кода: выполнить `python manage.py migrate`, собрать активный Tailwind CSS из `theme/static_src` командой `npm run build`, затем запустить `collectstatic`.
