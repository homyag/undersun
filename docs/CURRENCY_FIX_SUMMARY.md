## 🔧 Технические детали:

### Валюты по языкам:
- **ru**: RUB (₽) - русские рубли для русскоязычных пользователей
- **en**: THB (฿) - тайские баты для английского
- **th**: THB (฿) - тайские баты для тайского
- **Другие/неизвестные**: THB (฿) - базовая валюта

### API эндпоинт:
- **POST /currency/change/** - AJAX смена валюты
- Возвращает: `{"success": true, "currency": "USD", "symbol": "$"}`
- Сохраняет в сессии: `request.session['currency'] = 'USD'`

### Курсы валют:
- **База**: THB (тайский бат)
- **Поддерживаемые**: USD, RUB, THB  
- **API**: `/currency/rates/` - JSON с курсами
- **Команда обновления**: `python manage.py update_exchange_rates`
