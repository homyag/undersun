# ТЗ для извлечения данных из YouTube-субтитров

Этот файл используется как инструкция для ChatGPT: пользователь вставляет URL YouTube-видео, а ChatGPT извлекает из субтитров структурированные данные для дальнейшей подготовки контента Undersun Estate.

## Как использовать

1. Открой этот файл в ChatGPT.
2. Ниже в блок `Входные данные` вставь URL видео.
3. Если ChatGPT не может получить субтитры по ссылке, он должен попросить вставить транскрипцию вручную. Нельзя додумывать содержание видео без субтитров.
4. После анализа ChatGPT должен вернуть результат строго в формате из раздела `Формат ответа`.

## Входные данные

```text
YouTube URL:

Целевая задача:
- извлечь экспертные данные по районам, локациям, недвижимости, инфраструктуре и покупательским сценариям Пхукета;
- подготовить материал, который можно использовать для страниц районов/локаций, каталога, карточек объектов, FAQ и внутренних ссылок Undersun Estate.

Целевые языки сайта:
- ru
- en
- th
```

## Главные правила

- Используй только данные из субтитров или явно доступной транскрипции.
- Не придумывай факты, цифры, расстояния, сроки, цены, названия проектов и юридические выводы.
- Если факт звучит неуверенно или может быть ошибкой автосубтитров, пометь его как `needs_review`.
- Не вставляй в финальный контент фразы вроде `в видео говорится`, `автор ролика сказал`, `согласно видео`, `на YouTube`.
- Видео является внутренним источником фактуры, но страницы сайта не должны ссылаться на видео как на источник.
- Не делай юридических, налоговых, визовых или инвестиционных гарантий.
- Не обещай доходность, рост цены, ликвидность или успешную сделку.
- Сохраняй практичный тон агентства недвижимости: конкретика, условия, ограничения, кому подходит, что проверить перед покупкой.

## Что нужно извлечь из субтитров

### 1. География

Выдели все упомянутые районы, локации, пляжи, дороги, торговые зоны, школы, госпитали, марины и значимые ориентиры.

Для каждого элемента укажи:

- название как в субтитрах;
- нормализованное название для сайта;
- возможные варианты написания на русском, английском и тайском, если они очевидны;
- к какому району или локации это относится;
- уверенность: `high`, `medium`, `low`, `needs_review`.

### 2. Профиль района или локации

Для каждой найденной локации выдели:

- общий характер района;
- кому подходит: жизнь, отдых, инвестиции, аренда, семейное проживание, релокация, коммерция;
- какие типы объектов чаще уместны: виллы, кондо, апартаменты, таунхаусы, земля, коммерческие объекты;
- сильные стороны;
- ограничения и риски;
- что обязательно проверить перед покупкой или арендой.

### 3. Инфраструктура и логистика

Собери факты про:

- пляжи и доступ к морю;
- время в пути, если оно прямо названо;
- дороги, пробки, подъезды, транспортную доступность;
- школы, детскую инфраструктуру, госпитали;
- торговые центры, рынки, рестораны, кафе;
- аэропорт, марины, деловые зоны;
- шум, плотность застройки, сезонность, туристическую нагрузку.

Если в субтитрах есть расстояние или время, обязательно укажи, что это `source_claim`, а не универсальная гарантия.

### 4. Недвижимость и покупательские сценарии

Выдели:

- какие объекты подходят под покупку для жизни;
- какие объекты подходят под инвестиции;
- что может быть интересно для аренды;
- где важна ликвидность;
- где нужно осторожнее относиться к цене, управлению, состоянию объекта или окружению;
- какие вопросы покупатель должен задать агенту до просмотра.

### 5. Риски и ограничения

Отдельно выпиши все практические caveats:

- шум;
- пробки;
- сложный подъезд;
- стройка рядом;
- сезонность спроса;
- удаленность от пляжа;
- состояние проекта;
- управление комплексом;
- юридические ограничения;
- особенности freehold/leasehold, если они прямо упомянуты;
- завышенные ожидания по доходности.

Если риск является выводом, а не прямым фактом из субтитров, пометь его как `inference`.

### 6. SEO и структура страницы

Для каждой локации предложи:

- короткий экспертный summary для страницы;
- H2/H3 темы, которые стоит раскрыть;
- FAQ-вопросы по реальным интентам покупателей;
- внутренние ссылки, которые логично добавить:
  - каталог объектов в районе;
  - виллы;
  - кондо;
  - земля;
  - аренда;
  - услуги покупки;
  - услуги продажи;
  - юридическое сопровождение;
  - релевантные статьи блога.

Не создавай keyword stuffing. Формулировки должны быть полезны человеку и понятны поисковому роботу.

### 7. E-E-A-T и экспертность

Выдели факты, которые помогают показать опыт Undersun Estate:

- локальные наблюдения;
- практические советы перед просмотром;
- сравнения районов;
- ограничения, о которых обычно не пишут в рекламных описаниях;
- признаки хорошего или проблемного объекта;
- вопросы, которые агент должен проверить до рекомендации.

Не пиши `мы эксперты` или `E-E-A-T`. Нужно показать экспертность через конкретные детали.

## Формат ответа

Ответ должен быть в Markdown.

### 1. Краткая выжимка

```markdown
## Краткая выжимка

- Главная тема видео:
- Какие районы/локации затронуты:
- Основная польза для сайта:
- Что требует ручной проверки:
```

### 2. Таблица фактов

```markdown
## Таблица фактов из субтитров

| Факт | Категория | Локация | Уверенность | Тип | Как использовать |
|---|---|---|---|---|---|
| ... | инфраструктура | Bang Tao | high | source_claim | блок о логистике |
```

Категории:

- `geography`
- `infrastructure`
- `property_type`
- `buyer_intent`
- `investment`
- `rent`
- `risk`
- `legal`
- `lifestyle`
- `internal_linking`
- `faq`

Тип:

- `source_claim` - прямо сказано в субтитрах;
- `inference` - аккуратный вывод из нескольких фрагментов;
- `needs_review` - нужно проверить вручную.

### 3. Карточки локаций

```markdown
## Карточки локаций

### Location: bangtao

**Нормализованное название:** Bang Tao / Банг Тао

**Профиль:** ...

**Кому подходит:** ...

**Типы объектов:** ...

**Инфраструктура:** ...

**Что проверить перед покупкой:** ...

**Риски и ограничения:** ...

**Идеи для внутренних ссылок:** ...

**FAQ:**
- Вопрос:
  Ответ:
- Вопрос:
  Ответ:

**Что нельзя использовать без проверки:**
- ...
```

### 4. Черновик текста для страницы

Для каждой локации подготовь черновик на русском языке. Это не финальный рекламный текст, а основа для редактора.

```markdown
## Черновик текста для страницы

### Bang Tao

Короткий абзац 1.

Короткий абзац 2.

Что важно проверить перед покупкой:
- ...
- ...
```

Требования к черновику:

- не ссылаться на видео;
- не упоминать субтитры;
- не использовать неподтвержденные цифры;
- не обещать доходность;
- писать как локальный специалист по недвижимости на Пхукете;
- оставлять спорные места в виде `[проверить: ...]`.

### 5. JSON для дальнейшей обработки

В конце ответа добавь компактный JSON.

```json
{
  "source_url": "",
  "locations": [
    {
      "slug": "",
      "name_ru": "",
      "name_en": "",
      "profile_ru": "",
      "buyer_fit_ru": [],
      "property_types": [],
      "infrastructure": [],
      "risks": [],
      "faq_ru": [
        {
          "question": "",
          "answer": ""
        }
      ],
      "internal_links": [],
      "needs_review": []
    }
  ]
}
```

## Контроль качества перед финальным ответом

Перед тем как вернуть результат, проверь:

- нет ли ссылок на видео в готовых текстах;
- все сомнительные факты помечены как `needs_review`;
- нет юридических, налоговых, визовых или доходных гарантий;
- нет общих SEO-фраз без фактической пользы;
- каждая локация содержит не только плюсы, но и практические ограничения;
- текст можно использовать на мультиязычном сайте недвижимости без риска вводить покупателя в заблуждение.
