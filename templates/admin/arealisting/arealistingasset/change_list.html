Как работать с материалами

Здесь хранятся исходные фото, планировки и документы AREALISTING. Статус «Только URL» означает, что файл ещё не скачивали; документам локальный файл обычно не нужен.

    {% if can_retry_assets %}
  1. Чтобы исправить ошибку изображения, выберите фильтр «С ошибкой», отметьте нужные строки и запустите действие «Повторить скачивание выбранных изображений».
    2. {% endif %} {% if can_view_asset_groups %}
  2. Откройте материал, перейдите в подходящую группу и нажмите «Проверить и импортировать фотографии и планировки». Загрузка идёт в фоне; скачанный файл сам по себе в карточке не появляется.
    3. {% endif %}
  3. Если ошибка остаётся, откройте материал: в поле «Последняя ошибка» указана причина. Исправление недоступной ссылки или неверного формата требует обновления данных у источника.
{% if can_retry_assets %}

За один запуск можно повторно скачать до 10 изображений. Неактивные материалы и документы пропускаются.

{% endif %}
